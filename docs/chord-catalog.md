# 코드 사전

## 1부. 제공하는 코드와 사용법

표준 튜닝(E A D G B E), 오른손 기타 기준으로 **180개 코드·213개 운지**를 제공한다. 12개 근음과 아래 15개 종류의 모든 조합을 포함한다. ♯와 ♭로 이름만 다른 코드는 중복 집계하지 않는다. 가능한 모든 변형 코드·슬래시 코드·전위·확장음을 뜻하는 범위는 아니다.

### 보기와 검색

- **카드**: 코드 이름과 기본 운지표를 두 열로 확인한다. 접근성 글자 크기에서는 한 열로 표시한다.
- **코드표**: 세로는 근음, 가로는 종류다. 가로·세로로 스크롤하며 같은 근음이나 종류의 운지를 비교한다. 운지표를 누르면 상세로 이동한다.
- 두 보기에서 근음·종류 필터와 검색을 조합한다. `Bb`, `B♭`, `A#`, `A♯`는 같은 근음으로 검색한다. `마이너`, `major 7`, `Cø7`, `C+`도 지원한다.
- 상세에서는 손가락 번호·음이름을 전환하고 현별 프렛·음·손가락을 확인한다. 대체 운지가 있는 코드만 운지 선택기를 표시한다.
- 각 운지표의 왼쪽은 6번 현이다. ○는 개방현, ×는 뮤트이며 연결된 막대는 바레다. 위쪽 너트가 없으면 시작 프렛 번호를 읽는다.

### 종류와 구성음

도수는 근음의 메이저 스케일 기준이다. 9는 2와 같은 음이름이며, dim7의 𝄫7은 6과 같은 음높이다. add9에는 7도가 없고, 9에는 ♭7이 포함된다. 일반적인 개방형 C7은 완전5도만 생략하며 근음·3도·♭7은 유지한다.

## 2부. 데이터·검증과 참고

### 운지 데이터

`muttan/Features/Chords/chords.json`이 앱 데이터의 원본이다. 기존 12개 코드·24개 운지는 유지한다. Cmaj7, C7, Cadd9, Dmaj7, Dm7, Dsus2, Dsus4, E7, Em7, Esus4, Amaj7, Am7, Asus2, Asus4, G7, B7, C6, A6, Am6, E6, Em6에는 개방현 운지를 먼저 배치하고 이동형 대체 운지를 제공한다. 나머지 추가 코드는 동일 종류의 이동 가능한 운지 형태를 근음에 맞게 옮겨 제공한다. 모든 코드에 개방현 운지가 있는 것은 아니다.

프렛·손가락 배열은 6번→1번 현 순서다. null은 뮤트, 0은 개방현, 1–4는 손가락 번호다. 바레의 프렛·시작 현·끝 현·손가락은 명시적으로 저장한다. 사진이나 AI 이미지 자산은 사용하지 않는다.

### 검증

`./scripts/check-models.sh`로 앱과 동일한 디코딩·검증 함수를 실행하고 검색 별칭, 종류별 12개 근음, 잘못된 구성음의 거부를 검사한다. Python 검사에서는 180개 조합의 누락·중복, 운지 ID, 프렛·손가락, 중복 손가락의 바레 연결과 구성음을 검사한다. 이는 음악적 일관성과 데이터 구조 검증이며, 213개 운지를 사람이 모두 실제 연주해 검증했다는 의미는 아니다.

`./scripts/capture-ui-screenshots.sh --screens chords,chord-chart,chord-detail`로 목록·코드표·상세의 라이트/다크 캡처를 생성한다.
