# 연습 시제품: 비행기

## 1부. 사용자 경험과 동작

### 목표와 범위

기타를 보지 않고도 다음 음을 알고, 자기 속도로 한 음씩 따라 치며, 틀린 음 직후 그 부분을 다시 연습한다. 첫 시제품은 표준 튜닝의 멜로디 단음만 인식한다. 코드, 반주, 계정, 점수, 기록, 연속 연습 보상은 구현하지 않는다.

화면명은 `연습`, 곡 이름은 `비행기`로 한다. 탭에는 곡 선택 목록 대신 한 곡의 시작 카드가 있고, 누르면 곧장 연습 화면으로 들어간다. 시제품 결과가 좋으면 곡 목록으로 확장한다.

### 연습 화면

1. 상단에는 뒤로가기, `비행기`, 키와 속도 메뉴만 둔다. 기본 조성 C, 기본 속도 분당 72박이다.
2. 화면 중심에는 현재 음을 큰 오선 악보와 기타 타브로 함께 보여준다. 오선은 음높이를, 타브는 현·프렛을 알려준다. 현재 음은 강조색으로 표시한다.
3. 현재 음 주변에 이전 1음과 다음 3음을 작게 표시한다. 다음 음을 미리 읽을 수 있으나 화면 전체를 작은 악보로 채우지 않는다. 두 마디 이상 앞서가는 자동 스크롤은 하지 않는다.
4. 악보 아래에는 현재 음이름(`C4` 등), 현·프렛(`2번 현 · 1프렛`), 박자 진행 막대를 둔다. 정답 중복 텍스트나 퍼센트 점수는 표시하지 않는다.
5. 아래쪽 주요 조작은 `다시 듣기`, `느리게`, `일시 정지`다. 가로폭에 따라 느리게는 속도 메뉴에 넣는다. 다시 듣기는 현재 한 마디의 기준 음을 재생하고, 연습 입력은 잠시 정지한다.
6. 시작 전에는 짧은 두 박자 카운트인을 주고 첫 음을 기준음으로 들려준다. 그 뒤 화면 악보가 박자에 맞춰 진행한다. 소리는 기본으로 끄고 사용자가 악보와 메트로놈만으로 연습할 수 있게 한다. 소리 켜기는 명확한 토글로 제공한다.
7. 음이 맞으면 현재 음이 민트색 체크로 바뀌고 다음 박으로 자연스럽게 넘어간다. 반응 진동은 설정에서 끌 수 있게 한다.

### 비행기 멜로디

초기 악보는 C장조, 4/4, 분당 72박으로 둔다. 한 마디는 4박이며, 1박 음 6개와 2박 음 1개로 총 8박을 구성한다. 익숙한 전체 선율을 12마디로 한 번 연주한다. 아래 1–4마디의 순서를 5–8마디에서 반복하고, 9–12마디는 1–4마디를 반복한다. 곡의 편곡과 옥타브는 앱 안에서 검증한 뒤 JSON에 고정한다.

| --- | --- |
| 1 | C4(1), C4(1), G4(1), G4(1) |
| 2 | A4(1), A4(1), G4(2) |
| 3 | F4(1), F4(1), E4(1), E4(1) |
| 4 | D4(1), D4(1), C4(2) |
| 5 | C4(1), C4(1), G4(1), G4(1) |

각 이벤트는 순서, MIDI 음높이, 시작 박, 길이, 악보 표기, 기타 현·프렛을 가진다. 반복 음 사이에는 새로 튕긴 소리를 구분할 수 있는 짧은 음 끊김을 편곡에 둔다. 연속 같은 피치가 한 번의 지속음으로 들어오면 두 음을 모두 통과시키지 않는다.

### 음정 판정

- 기존 마이크 권한과 YIN 단음 추정기를 재사용한다. 코드 화음 인식이나 음원 분리라고 표현하지 않는다.
- 기대 음 주변 ±50 cent를 맞는 음으로 판정한다. ±50–100 cent에서는 `조금 높아요` / `조금 낮아요`를 짧게 보여주며 음을 틀린 것으로 확정하지 않는다. 100 cent 초과의 다른 안정된 음이 들어오면 오답 후보로 처리한다.
- 마이크 입력은 프레임 연속 데이터다. 소리가 충분한 레벨·신뢰도를 유지하는 여러 연속 프레임에서만 음을 확정해 잡음에 의한 오답을 막는다. 무음·저신뢰 구간은 실패가 아니며 진행과 오답 타이머를 멈춘다.
- 같은 음 두 번은 피치가 같다는 이유로 한 음만 통과시키지 않는다. 각 목표 박마다 소리 시작을 확인하고, 이전 음과 구분되는 짧은 무음 또는 신호 감소를 거친 뒤 다음 발음을 받는다.
- 박자 허용 범위는 기본 목표 시작 시각의 ±35%다. 사용자가 `느리게`를 선택하면 속도는 0.75배, 0.5배로 낮출 수 있고 판정 창도 실제 재생 박에 비례한다. 자동 적응 속도나 점수는 없다.
- 잘못된 프렛을 울렸지만 음높이가 목표와 같은 경우 마이크로는 현·옥타브를 확정하기 어렵다. 그 음은 음정 기준으로 통과시키고, 해당 한계를 튜너처럼 설명하지 않는다. 화면에는 연주할 현·프렛을 계속 보여준다.

### 자연스러운 되감기와 자동 재시작

- 맞지 않는 안정된 음이 목표 음 입력 구간에서 감지되면 즉시 `다시 들어볼게요`라는 짧은 안내와 함께 진행 표시를 멈춘다. 틀린 음 재생의 꼬리가 자연스럽게 사라지도록 약 300ms 기다린다.
- 재생 위치를 정답/오답 이벤트의 시작점보다 **1.5초 전**으로 옮긴다. 곡 처음으로 돌아가지 않고 한 마디 안의 해당 부분으로 이동한다. 첫 1.5초 안의 오류는 곡 시작에 고정한다.
- 점프 후 300ms 숨 고르기와 두 박자 카운트인을 자동 재생하고, 그 위치부터 기준음을 작게 들려주며 연주를 재개한다. 재시작 버튼을 누르게 하지 않는다.
- 오답 하나에 한 번만 되감는다. 카운트인 중 마이크는 입력을 무시한다. 같은 오류를 연속 판정해서 무한히 되감지 않게 한다. 재개 후에는 사용자 입력을 다시 기다린다.
- 소리 입력이 없으면 곡 진행을 자동으로 앞당기지 않는다. 타이밍을 놓치면 화면의 `계속` 버튼으로 현재 이벤트를 넘길 수 있고, 연속 두 이벤트를 넘겼으면 해당 마디의 처음으로 이동한다.
- 오답 횟수·통과율은 저장하거나 성취 점수로 만들지 않는다. 되감기는 현재 세션에만 적용하며 앱을 나가면 초기화한다.
- 자동 점프를 사용자가 원치 않을 수 있으므로 기본값은 켜되, 화면에 `자동 다시 시작` 토글을 둔다. 끄면 오답 위치에서 멈추고 `이 부분 다시`와 `계속` 두 동작을 제시한다. 반복해서 같은 실수를 하는 상황에서는 현재 마디만 반복하는 선택을 제공한다.

### 오디오 상태와 안전한 중단

- 마이크 권한은 연습 진입 시 요청하고, 거부 시 설정으로 연결되는 안내를 표시한다. 캡처 미리보기는 권한을 요청하지 않는다.
- 녹음 중 앱은 오디오를 저장·전송하지 않는다. 분석은 기기에서만 한다.
- 연습 시작 전 튜너의 입력 세션을 정리하고, 연습 이탈·백그라운드 전환 시 연습 엔진과 오디오 tap을 정리한다. 튜너와 연습이 동시에 마이크를 점유하지 않는다.
- 전화·오디오 중단 후 앱에 돌아왔을 때 자동 재생하지 않는다. 사용자에게 `다시 시작`을 보여주고 카운트인부터 재개한다.
- 입력 오류, 권한 변경, 오디오 세션 중단, 화면 이탈은 세션 식별자로 구분하여 이전 분석 결과가 새 세션 화면을 바꾸지 않게 한다.

### 완료 상태

12마디 재생이 끝나면 간단한 `끝까지 연주했어요`와 `처음부터`만 표시한다. 점수, 별, 배지, 시간, 연속 일수, 소셜 공유는 만들지 않는다.

## 2부. 기술 계획과 검증

### 구현 단계

1. 12마디 악보·타브 이벤트 JSON과 메타데이터를 만든다. 코드사전의 현·프렛 데이터를 공유할 수 있도록 음 이벤트 모델과 운지 모델을 분리한다.
2. 재생 시계, 카운트인, 마디 루프, 현재·다음 음 악보 스크롤을 오디오 입력과 분리한 순수 상태 모델로 구현한다.
3. 기존 `PitchDetector` 위에 연속 음정, 신뢰도, 에너지, 새 음 시작을 묶는 판정기를 둔다. 오디오 tap에서 UI 상태를 직접 바꾸지 않고 직렬 이벤트를 전달한다.
4. 오답 판단 위치와 시각을 세션 이벤트로 보존하고, 1.5초 이동·중복 방지·카운트인·자동 재개 상태 전이를 구현한다. 무음에서 오답이 쌓이지 않는지 확인한다.
5. 녹음 권한과 화면 수명 주기를 기존 튜너와 조정하고, 오디오 세션 단일 소유를 보장한다.
6. 실제 iPhone에서 표준 튜닝 기타를 사용해 단음, 반복음, 오답, 무음, 잡음, 지연, 앱 백그라운드 전환을 점검한다. 시뮬레이터의 가짜 음정은 화면 캡처에만 사용한다.

### 시험 기준

- 권한 거부·허용, 시작·종료, 앱 중단 후 재개가 올바른 화면 상태를 보여준다.
- 각 목표음의 올바른 음은 한 번만 진행시키고, 불안정한 잡음·무음은 진행시키지 않는다.
- 반복 음 두 개는 각기 다른 발음으로 감지되어야 한다.
- 안정적으로 틀린 음을 입력하면 현재 음을 오답으로 표시하고 1.5초 앞 위치로 되감아 카운트인 후 자동으로 재개한다.
- 가장 앞의 오류는 곡 처음으로 이동한다. 마디를 벗어나는 점프, 오답 연속 발생으로 인한 점프 루프, 이전 세션 결과의 유입이 없어야 한다.
- 자동 재시작을 끄면 정지 위치에서 `이 부분 다시`와 `계속`이 동작한다.
- 0.5배·0.75배·기본 속도에서 표시 박자·입력 허용 구간·되감기 위치가 같은 시간축을 사용한다.
- 화면은 라이트·다크 및 큰 글씨에서 오선·타브·현재 음·주요 동작이 겹치지 않는다.
- 가사는 표시하지 않는다. 곡의 음표·기준음 샘플은 이 시제품에 필요한 멜로디만 직접 작성한다.

### 구현 상태

기획 문서만 작성했다. 오선·타브 악보, 곡 데이터, 오디오 세션, 판정기, 되감기, 화면은 미구현이다.
