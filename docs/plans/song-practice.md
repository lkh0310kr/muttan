# 연습·곡 화면과 공용 Play

## 화면 구조

앱 하단의 `연습` 탭은 짧은 기타 기술 훈련, `곡` 탭은 따라 칠 곡 목록을 보여준다. 목록 카드에서 항목을 누르면 중간 상세 페이지 없이 공용 `Play` 화면으로 이동한다. 화면 제목은 현재 항목 이름으로 표시하고, 악보 영역만 훈련 또는 곡에 맞게 바꾼다.

첫 훈련은 한 줄의 개방현부터 3프렛까지 한 박씩 치는 `한 줄 0·1·2·3`이다. 기본은 1번 현과 60 BPM이며 반복한다. 이후 훈련은 음 이벤트마다 현·프렛을 지정하므로 한 현 연습, E·D 현 전환, 여러 현 연습을 같은 방식으로 표현할 수 있다.

곡 목록의 첫 곡은 `비행기`다. C장조, 4/4박자, 72 BPM의 12마디 단음 멜로디를 사용한다. 실제 이벤트 데이터는 앱 번들 [practice-content.json](../../muttan/Features/Practice/practice-content.json)에 둔다.

## 공용 Play 동작

- 플레이 화면에는 콘텐츠 제목, 속도, 현재 음, 현·프렛, 다음 몇 음, 진행 상황과 재생 상태를 표시한다. 곡에서는 오선과 타브를 함께 보여주고, 훈련에서는 현재 운지와 다음 운지에 집중한다.
- 사용자가 `연습 시작`을 눌렀을 때 마이크 권한을 확인하고 실시간 입력을 연다. 처음에는 소리 없이 화면에 2박 카운트인을 표시한 뒤 입력을 받는다. 오디오는 기기에만 사용하며 저장하지 않는다.
- 현재 음은 YIN으로 추정하고, 에너지 상승으로 새 타격을 구분한다. 목표 MIDI에서 ±50센트 안의 유효 음이 연속 분석 프레임에서 확인되면 다음 이벤트로 진행한다. 타격 시각은 목표 박 기준 ±35% 안에 있어야 한다.
- 안정적인 다른 음이 들어오면 약 1.5초 앞의 이벤트로 돌아가 2박 카운트인 뒤 다시 시도한다. 콘텐츠 시작보다 앞은 첫 이벤트로 제한한다. 무음·저신뢰 입력은 오답으로 처리하지 않는다.
- 입력이 없으면 자동으로 다음 이벤트로 넘어가지 않는다. `계속`은 현재 이벤트를 넘기며, `일시 정지`와 `처음부터`는 입력 세션을 정리한 뒤 상태를 초기화한다.
- 화면 이탈, 다른 탭 선택, 앱 백그라운드 전환, 오디오 중단·라우트 변경 시 입력 엔진과 tap을 중지한다. 복귀 후 자동 재개하지 않는다.

## 구현 상태와 확인 기준

현재 탭은 `연습`, `곡`, `코드`, `튜너`, `설정` 순서이며 앱 시작 탭은 `연습`이다. 연습 탭에는 0·1·2·3 훈련, 곡 탭에는 비행기가 있다. 두 항목은 같은 Play 화면을 사용한다.

- 각 목록 카드에서 바로 공용 Play 화면에 진입하고 화면 내용이 선택한 훈련·곡과 일치한다.
- 정답 음은 한 번 진행시키고, 무음·불안정한 신호는 진행시키지 않는다. 반복 타격은 별도 이벤트로 구분한다.
- 안정적인 오답에서만 되감기와 카운트인을 수행하며, 여러 분석 프레임이 중복으로 되감기를 예약하지 않는다.
- 마이크 거부, 시작 실패, 탭 전환, 백그라운드, 전화 중단, 입력 장치 해제에서 안내와 정리가 올바르게 동작한다.
- 라이트·다크 모드의 목록 및 플레이 화면을 스냅샷으로 확인한다. 마이크 입력 품질과 지연은 실제 iPhone·기타로 확인한다.

점수, 학습 기록, 코드 인식, 반주, 계정, 소셜 기능은 범위에 포함하지 않는다.
