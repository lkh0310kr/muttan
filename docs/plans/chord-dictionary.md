# 코드 사전 구현 계획

## 제품 동작

학습 프로토타입을 코드 탭으로 교체하고 코드·튜너·설정 3개 탭을 제공한다. 초기 화면은 코드 목록이며 검색과 종류 필터를 조합한다. 상세 화면에서 기본·대체 운지를 전환한다. 제품 명세는 [PRD](../PRD.md)를 따른다.

## 데이터와 화면

- 번들 JSON을 `Chord`, `ChordQuality`, `ChordVoicing`으로 해석한다.
- 코드는 ID, 기호, 종류, 근음, 운지 목록을 가진다. 운지는 ID, 이름, 6번→1번 현의 프렛·손가락 배열, 바레 정보를 가진다. 프렛 null은 뮤트, 0은 개방현이다.
- 음은 표준 튜닝과 프렛에서 계산한다. 데이터 오류는 임의 대체값으로 숨기지 않고 오류 화면에 표시한다.
- 운지표는 동일 컴포넌트로 목록과 상세에서 그린다. 상세는 현별 운지 설명을 VoiceOver에 제공한다.

## 구현 순서와 검증

1. 문서 명세를 반영하고 별도 커밋한다.
2. 12개 코드·24개 운지, 코드 사전, 운지표, 검색·필터를 구현하고 학습 프로토타입을 제거한다.
3. 데이터 검증 스크립트로 ID 중복, 배열 길이, 운지 수, 프렛·손가락·바레 범위와 코드 구성음 일치를 검사한다. Swift 모델의 검색·필터도 실행 검증한다. 시뮬레이터 빌드를 확인하고 구현을 커밋한다.
4. 캡처 경로 `chords`, `chord-detail`을 등록한다. 상세 목은 F 기본 바레 코드로 고정한다. 튜너·설정과 함께 라이트/다크 8장을 생성하고 캡처 변경을 커밋한다.

## 완료 기준

12개 코드가 두 운지씩 표시되고, 검색과 필터·결과 없음·상세 이동·운지 전환이 동작한다. 개방현·뮤트·바레가 정확히 표시되고 모든 구성음이 해당 코드에 포함된다. 마이크 권한이나 네트워크 없이 사용할 수 있다.

## 구현 결과

- 코드·튜너·설정 3개 탭과 코드 목록·상세 화면 구현 완료.
- `python3 scripts/validate-chords.py`: 12개 코드와 24개 운지의 구성음·프렛·손가락·바레 검증 통과.
- Swift 모델 실행 검증: JSON 디코딩, 공백·대소문자 검색, 종류 필터 조합, 결과 없음, 구성음 계산 검증 통과.
- 시뮬레이터 빌드 통과. 코드 목록·F 상세·튜너·설정의 라이트/다크 8장 자동 생성.
- 목록과 F 상세의 양 테마 캡처를 시각적으로 확인. 실제 터치에 의한 탐색·운지 전환은 별도 UI 자동화로 검증하지 않았다.

## 운지 확인 개선

코드 기호 외 영문·한글 이름 검색을 지원한다. 상세에 손가락/음이름 전환과 현별 프렛·손가락·음 표를 추가하고, 바레의 중복 손가락 번호를 줄였다. 접근성 크기 목록은 1열로 표시한다. 현별 음 계산, 이름 검색, 필터 조합과 바레 접근성 설명은 모델 검사에 포함한다.

## 코드 수 확장과 코드표 (2026-11-05)

초기 12개 코드 범위를 12개 근음 × 15개 종류, 180개 코드·213개 운지로 확장했다. 상세 범위는 [코드 목록](../chord-catalog.md)에 정리했다. 기존 기본·대체 운지는 유지하고, 추가 운지는 코드당 최소 1개로 제공한다.

- 카드·코드표 전환, 근음·종류 메뉴 필터, 이명동음·ASCII/음악 기호 검색.
- 코드표는 행에 근음, 열에 종류를 배치하고 각 칸에 기본 운지표를 표시한다. 가로·세로 스크롤하며 누르면 상세로 이동한다.
- 종류가 많아진 만큼 종류 필터는 세그먼트에서 메뉴로 변경한다. 운지가 하나인 상세에서는 운지 선택기를 표시하지 않는다.
- 데이터 검증은 12 × 15 조합의 누락·중복, 필수 구성음·외부음, 손가락 중복·바레·프렛 범위를 검사한다. 보편적인 개방형 C7처럼 완전5도를 생략한 도미넌트7 운지를 허용한다.
- 앱과 Swift 검사에서 동일한 카탈로그 검증 함수를 사용한다. 모든 종류·근음의 검색 별칭을 검사한다.
- 자동 캡처에 `chord-chart`를 추가한다. 기존 기본 화면 4개와 함께 5개 화면 × 라이트/다크 총 10장을 생성할 수 있다.

사진 생성·외부 사진 도입은 중단했다. 이 작업에는 사진 자산이 포함되지 않는다.

검증 결과: Swift 모델·검색·잘못된 구성음 거부, Python 데이터 검사 통과(180개 코드·213개 운지). 시뮬레이터 빌드와 목록·코드표·F 상세의 라이트/다크 캡처를 확인했다. 실제 터치로 필터·스크롤·상세 이동을 수행하는 UI 자동화는 이번 작업에 포함하지 않았다.
