# Simply Guitar · 조사

## 제품 구조와 주요 기능

공식 도움말에서 확인되는 PLAY는 iOS의 노래 따라 연주 영역이다. 곡 화면 한곳에서 코드와 가사를 보며 스트럼하고, 필요한 코드를 화면 위에서 눌러 다이어그램·사진·짧은 영상을 확인한다. 즉, 곡 플레이와 필요한 코드 참고를 오가도록 연결한 흐름이다. 화면 회전 설명은 도움말에 상충하는 문구가 있어 방향 의존 사양으로 단정하지 않는다.

튜너 도움말은 음을 듣고 표준 기타 현을 맞추는 독립 도구를 안내한다. 공개 자료만으로는 노래·레슨의 음정 인식 모델, 정확도·지연·허용 오차, 실패 복구 알고리즘을 확인할 수 없다.
