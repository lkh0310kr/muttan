# Ultimate Guitar · 기능과 자료 구조 관찰

- 곡 자료: 코드, 탭, 가사, 동영상 링크·반주 자료.
- 탐색: 장르·평가·연주 난이도·튜닝 조건 및 주제별 컬렉션.
- 내 라이브러리: 즐겨찾기, 재생목록, 개인 편집 탭, 오프라인 즐겨찾기.
- 조정: 탭 좌우 모드, 글꼴·크기, 다크 모드, 코드 단순화·운지 대체, 조옮김.
- 재생: 동기화된 탭, 자동 스크롤, 템포·메트로놈, 반주.
- 악기 도구: 코드 사전과 튜너.

UG의 커뮤니티 기여 탭은 곡별 자료의 폭을 늘릴 수 있지만, 출처와 편곡이 다양하다. 공개 앱 설명과 사용자 리뷰에서 코드 정확도 차이가 언급되므로, 하나의 사용자 기여 자료를 검증된 원본 악보처럼 다루지 않는다.
