# Ultimate Guitar · UI·UX와 연주기

## 정보 구조

앱스토어 설명상 곡 검색·카탈로그와 개인 탭, 재생·연주 도구가 중심이다. 검색은 장르·평가·연주 수준·튜닝을 조건으로 활용한다. 즐겨찾기 탭은 컬렉션·재생목록에 모으고, 편집 가능한 Personal tabs, 오프라인 즐겨찾기, 좌우 손잡이 모드, 글꼴·크기·다크 모드를 제공한다고 안내한다.

## 따라 연주 화면

Pro 기능으로 인터랙티브 탭을 음 단위로 연주하고, 자동 스크롤, 박자기, 재생 속도 조절, 반주·동기화 가사를 제공한다. 코드 운지 대안과 Simplify 기능으로 어려운 곡을 쉽게 바꿔 연주할 수 있다. iOS App Store 공개 설명은 이 기능 집합을 확인해 주지만, 현재 각 화면에서 컨트롤 위치와 오답 시 화면 동작은 보여주지 않는다.

## UX 관련 관찰

- 화면 글자 크기, 좌우 손 설정, 다크 모드는 악보를 읽는 개인 조건을 직접 조정하게 한다.
- 복잡한 곡을 단순화하거나 다른 코드 운지를 고르는 제어가 연주 화면의 난도를 조절한다.
- 자동 스크롤은 속도 설정과 함께 제공된다고 설명한다. 사용자 리뷰에는 자동 이동이 예상과 다를 때 수동 스크롤을 선호한다는 의견도 있어, 수동 제어를 완전히 없애지 않는 편이 좋다. 리뷰는 개인 경험이며 전체 사용자를 대표하지 않는다.
