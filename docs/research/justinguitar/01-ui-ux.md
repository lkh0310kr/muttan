# Justin Guitar · 조사

## 앱 기능과 UI·UX

공식 앱 페이지는 노래 라이브러리와 노래 따라 연주, 영상, 튜너, 코드 전환 추적, 스트럼 보조 도구를 안내한다. Google Play 설명은 코드 필터가 있는 노래책과 조절 가능한 템포·가사를 가진 플레이어를 언급한다. 화면의 자세한 컴포넌트 배치나 현재 버전 iOS의 세부 상호작용은 제공된 자료만으로 확인하지 않았다.

코스와 노래 앱 도구가 결합되어 학습한 기법을 곡에 적용하고, 느린 템포에서 연습하며, 코드를 다시 확인하는 흐름을 제공한다. 진행 기록은 공개 제품 설명에 언급되지만, 이 프로젝트에서는 사용자 요구에 따라 개인 연습 이력은 설계 범위에 넣지 않는다.
