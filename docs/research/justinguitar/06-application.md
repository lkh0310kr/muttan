# Justin Guitar · 조사

## muttan에서 살펴볼 점

기본 동작을 작게 나누어 가르치고, 충분히 반복한 뒤 곡에 연결하는 교육 순서를 참고한다. 템포를 직접 낮추는 조작, 구간 반복, 코드표로 돌아가는 짧은 길도 사용자 주도성을 높인다. 단순한 0–3 프렛 연습의 화면에서 장기 커리큘럼 구조를 먼저 도입하지 않는다.

## muttan 적용 관점

짧은 손가락 연습에서 곧바로 노래 전체를 강제하기보다 “새 운지 → 반복 패턴 → 쉬운 곡에 적용”의 순서를 제안할 수 있다. 사용자가 반복 횟수나 속도를 스스로 고르는 편이 초보의 불안감을 줄인다. muttan은 개인용 도구이므로 Justin Guitar에 있는 진도·연습 추적을 자동 복제하지 않는다.
