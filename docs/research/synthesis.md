# 기타 학습 서비스 종합 비교

이 문서는 서비스별 자료를 같은 질문으로 비교한다. 표는 공개 출처에서 확인된 제품 설계를 요약하며, 효과의 우열을 증명하지 않는다. 자세한 근거는 각 서비스 문서에 링크했다.

## 1부. UI·UX와 연습 인터랙션

| 서비스 | 시작과 탐색 | 연주 화면·상호작용 | 반복·속도 제어 |
|---|---|---|---|
| [Simply Guitar](simply-guitar/01-ui-ux.md) | 강의 경로, Songs, 코드 사전과 PLAY 영역을 둔다. | PLAY는 코드와 가사 자동 스크롤, Basic/Full 스트럼, 코드별 빠른 참고를 둔다. PLAY는 정오답 채점을 하지 않는다. | 공개 PLAY 안내에서 구간 루프·템포 변경은 확인되지 않음. |
| [Yousician](yousician/01-ui-ux.md) | 가이드 학습 경로에서 기술·곡을 연계하고 라이브러리와 일일 연습을 제공한다고 설명한다. | 실제 소리 입력과 맞는 음·타이밍에 대한 즉시 피드백을 제품 설명이 강조한다. 세부 현재 화면 배열은 공개 텍스트로 확인되지 않았다. | 신실라버스는 자기 속도 연습 사례를 설명하지만 현재 모든 플레이 모드에 같은 제어가 있는지는 미확인. |
| [Fender Play](fender-play/01-ui-ux.md) | My Path에서 다음 레슨을 안내하고 수준별 노래/리프를 배치한다. | 설명 영상, 타브형 Practice Mode, 악기 클로즈업과 타브가 있는 Play Along을 구분한다. Feedback Mode는 안내에서 베타 범위로 소개된다. | 자기 속도 진행을 제품이 설명한다. 특정 화면 속도 조절 세부는 공개 페이지에서 미확인. |
| [Justin Guitar](justinguitar/01-ui-ux.md) | Grade/Module 웹 수업과 별도 앱의 노래·연주 도구를 함께 제공한다. | 곡 플레이어와 코드·가사, 코드 전환 추적·스트럼 보조 도구를 앱 소개가 열거한다. 현 버전 전체 UI는 조사하지 못했다. | Google Play 설명은 조절 가능한 템포·가사를 명시한다. |
| [Ultimate Guitar](ultimate-guitar/01-ui-ux.md) | 곡·탭·코드를 직접 찾고 컬렉션/즐겨찾기에 정리한다. | 인터랙티브 탭, 동기화 가사·반주, 코드 대체와 Simplify를 안내한다. 사용자 맞춤 표시가 다양하다. | 템포, 메트로놈, 자동 스크롤, 조옮김을 제공한다고 App Store에 기재한다. |
| [Guitar Tricks](guitar-tricks/01-ui-ux.md) | 홈 또는 Learning Paths에서 단계식 기본 경로와 장르 코스로 진입한다. | 비디오 레슨과 검색, 학습 경로가 중심이다. | 영상 구간 반복과 레슨 재방문을 지원한다. |

## 2부. 기술·오디오에 관한 공개 근거

| 서비스 | 확인된 입력·출력 사실 | 공개되지 않은 내용 |
|---|---|---|
| Simply Guitar | 마이크 권한 안내, 기타 음 인식 문제 해결, 리드 음과 코드 연주 팁을 제공한다. 배경 음악이 마이크에 들어갈 수 있어 헤드폰을 권한다. | 모델·알고리즘, 로컬/서버 처리 경계, 허용 오차, 구간 재시작 로직. ([기술 노트](simply-guitar/02-technology.md)) |
| Yousician | 회사는 실제 연주를 듣고 음·코드 및 타이밍 피드백을 주는 사운드 인식 기능을 설명한다. | 분석 알고리즘, 온셋 검출과 정확도 허용창, 서버 처리 구조. ([기술 노트](yousician/02-technology.md)) |
| Fender Play | Feedback Mode 도움말은 연주 피드백과 예제·반주 오디오, 헤드폰 사용을 안내한다. | 음정 모델·채점식·지연값. 기능은 일부 활동의 베타로 설명된다. ([기술 노트](fender-play/02-technology.md)) |
| Justin Guitar | 앱 소개는 튜너·코드 전환 추적 등 도구를 나열한다. | 단음 채점 알고리즘, 자동 오답 복구. ([기술 노트](justinguitar/02-technology.md)) |
| Ultimate Guitar | 동기화 탭과 재생 컨트롤, 내장 튜너를 설명한다. | 음향 입력을 이용한 오답 판정이 탭 기능에 포함되는지 확인되지 않는다. ([기술 노트](ultimate-guitar/02-technology.md)) |
| Guitar Tricks | 영상 수업과 반복 미디어 재생 관련 기능이 확인된다. | 기타 소리 인식·실시간 채점. ([기술 노트](guitar-tricks/02-technology.md)) |

## 3부. 커리큘럼 설계

- **기초 기술을 짧게 소개한 뒤 자기 속도 연습과 짧은 곡 적용**: Yousician의 실라버스 설명과 Fender의 곡·리프 단위 안내에서 확인되는 구조다.
- **기본 경로와 관심 장르의 경로를 구분**: Simply Guitar는 Lead/Chords와 합성 경로를, Fender는 기초 학습 경로와 Song/Riff 콘텐츠를 설명한다.
- **지도 영상과 곡 플레이 자료를 목적별로 분리**: Fender는 Practice Mode(타브)와 Play Along을 구분한다. Guitar Tricks와 Justin Guitar는 비디오 설명과 반복 실습을 경로 안에 둔다.
- **학습 자료를 한 곡에 연결**: Simply는 곡 화면에서 코드를 열고, Ultimate Guitar는 탭·코드·가사를 라이브러리로 묶는다.
- **개인용 첫 연습**: 전체 커리큘럼을 흉내 내기보다 한 현에서 개방·1·2·3프렛을 하나씩 누르는 성공 가능한 행동과 다음 행동을 안내하는 편이 현재 범위에 맞다.

상세: [Simply](simply-guitar/03-curriculum.md), [Yousician](yousician/03-curriculum.md), [Fender](fender-play/03-curriculum.md), [Justin Guitar](justinguitar/03-curriculum.md), [Ultimate Guitar](ultimate-guitar/03-curriculum.md), [Guitar Tricks](guitar-tricks/03-curriculum.md).

## 4부. 기능 비교와 우선순위

| 문제 | 서비스에서 확인한 접근 | muttan 고려 |
|---|---|---|
| 다음 학습 행동이 불분명함 | 순차 학습 경로(My Path/Core Path) | 연습 화면에 목표 프렛과 현재 진행 위치만 명확히 표시 |
| 악보를 보며 연주하기 어려움 | 타브·코드·가사와 자동 또는 수동 재생기 | 한 현의 0·1·2·3 타브를 크게 표시하고 다음 한두 동작만 예고 |
| 어려운 파트 반복 | 영상 구간 루프, 단계식 섹션, 조절 템포 | 오답 뒤 해당 음/직전 박으로 되돌리고 자동 재개를 간단히 토글 |
| 악보 읽기 조건 차이 | 글꼴·크기, 좌우 손, 조옮김·단순화 | 라이트/다크와 큰 글씨, 단순한 프렛 가이드를 우선 |
| 연주 입력이 잘 잡히지 않음 | 마이크 권한·주변 소음·헤드폰 안내 | 연습 진입 전 튜닝 확인, 입력 상태·무음 상태를 구별하고 오답으로 오인하지 않기 |

이 표의 적용 칸은 공개 서비스의 기능 효과가 실험으로 입증됐다는 뜻이 아니라, muttan의 단일 사용자를 위한 구체적인 제품 설계 제안이다.

## 5부. muttan 다음 시제품과 비범위

[0–3 프렛 한 현 연습 계획](../plans/song-practice.md)을 갱신해 현·프렛 선택, 박자, 입력 허용창과 오류 복귀 규칙을 확정한 뒤 개발한다. 곡 탭은 연습 데이터와 분리된 비어 있는 탐색 구조로 두거나, 기능을 실제 제공하기 전까지 숨기는 것이 일관된다. 계정·경쟁·연습 기록·점수는 넣지 않는다.

## 6부. 연구 한계와 갱신 기록

각 자료는 제조사 도움말·제품 설명·앱스토어의 기능 기술에 의존한다. 가격·지역별 콘텐츠·접근성 세부·현재 로그인 상태의 모든 UI를 확인한 완전한 제품 감사는 아니다. 알고리즘 등 내부 정보가 문서에서 발견되지 않으면 미확인으로 남겨 둔다.
