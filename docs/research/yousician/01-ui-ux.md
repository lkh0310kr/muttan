# Yousician 기타 · 조사

## UI·상호작용

- 연주할 음이나 코드를 시각적으로 제시하고, 실제 기타 입력을 듣는 상호작용을 제공한다.
- 공식 설명은 맞는 음과 박자에 관한 즉시 피드백을 강조한다.
- 타브·악보 읽기와 프렛보드 탐색은 재생 화면을 넘어 학습 자료로 제공된다.
- 설정, 난이도, 접근성에서 화면이 구체적으로 어떻게 달라지는지는 이 공개 자료만으로 검증하지 않았다.

## 화면 패턴에 관한 근거 한계

현재 공식 페이지는 영상·플레이 얼롱과 실제 연주 감지를 확인해 주지만 실제 앱 화면의 각 구성요소 크기, 진행 방향, 현재/다음 타브 정렬, 오답 후 재시작 정책은 설명하지 않는다. 이미지가 포함된 구형 공개 교육 안내서의 문자열 연습 화면은 화면에 “Play string 6, open”처럼 한 번의 명령과 개방현 스트로크를 크게 배치하는 학습 패턴을 보여준다. 이는 오래된 간접 자료이므로 현재 앱의 UI 사양으로 인용하지 않는다. [교육 안내서](https://seniorplanet.org/wp-content/uploads/2024/01/5.-Yousician-One-Pager-1.8.24.pdf)

## 공개된 실제 화면 예시

아래 이미지는 Yousician이 2021년 커리큘럼 개선 글에 올린 자기 속도 연습 화면이다. 화면 상단은 `Play the 2nd-thickest string open`이라는 단일 지시를 내고, 줄·프렛 상호작용을 중앙에 둔다. 이 이미지에서 목표 위치의 안내와 단일 동작에 집중하는 실제 디자인 패턴을 확인할 수 있다. 정해진 박자로 노트를 맞추는 화면은 아니며 자기 속도 연습 모드 예다.
