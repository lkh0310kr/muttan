# Yousician · 기능

공식 기타 페이지와 앱 설명이 확인해 주는 기능 층위:

- 안내식 기타 학습 경로 및 영상 수업
- 연주를 들으며 음·코드와 타이밍을 피드백하는 플레이 활동
- 노래·리프 라이브러리와 오늘의 리프 소개
- 탭·악보 읽기와 프렛보드 탐색(스토어 문구)
- 매일 맞춤 연습과 학습 진도 안내
- 기타 외 악기도 포함하는 제품군

공식 2021년 경로 개선 글에는 동영상 → 자기 속도 연습 → 짧은 노래로 구성된 학습 묶음 사례가 있다. 구체적인 현재 인앱 기능과 모든 곡에 대한 제공 여부는 수시로 달라질 수 있다.
