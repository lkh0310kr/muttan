# Guitar Tricks · UI·UX와 학습 경로

## 진입과 내비게이션

공식 도움말은 홈 화면에서 Core Learning System으로 들어가거나 Learning Paths 내비게이션 메뉴를 선택하는 두 경로를 안내한다. 메뉴는 화면 크기에 따라 왼쪽 또는 위쪽에 나타날 수 있다고 한다.

## 학습 단위

핵심 경로는 처음 기타를 잡고 튜닝하는 기초에서 기본 코드·스케일까지 순차적으로 이어진다. 개별 레슨을 다시 열 수 있고, 필요한 영상 구간을 반복 재생할 수 있다. 초급 코어 과정을 마친 뒤 Rock, Country, Blues, Acoustic 같은 중급 방향으로 이동한다.

## UX에서 관찰한 점

- 코스 맵을 통해 현재 기본 경로를 찾고, 검색으로 특정 기법을 바로 열 수 있다.
- 짧은 레슨의 특정 구간 루프는 전체 강의를 다시 재생하지 않고 어려운 설명만 반복하게 한다.
- 학습자가 막히면 반복 가능한 항목을 선택하도록 한다.

공식 지원 문서는 화면 캡처와 GIF를 포함하지만 본 문서는 정적 코드 조사다. 동영상 플레이어의 버튼 배치·자막·속도 제어를 검증하지 않았다.
