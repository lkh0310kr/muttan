# 타 서비스 조사

공개 제품·도움말 자료를 기준으로 기타 학습 서비스의 화면, 학습 흐름, 기술 공개 범위, 콘텐츠와 기능을 조사했다. 이 폴더는 서비스별 근거와 비교 내용을 모으고, 기술 조사 계획은 상위 `docs/research/README.md`에서 관리한다.

## 서비스별 조사

| 서비스 | 주요 관점 | 자료 |
|---|---|---|
| Simply Guitar | 영상 학습, 음향 피드백, 노래·코드 연습 | [조사 폴더](simply-guitar/README.md) |
| Yousician | 인터랙티브 연주, 자기 속도 연습, 학습 경로 | [조사 폴더](yousician/README.md) |
| Fender Play | 노래·리프 레슨, Play Along, Feedback Mode | [조사 폴더](fender-play/README.md) |
| Justin Guitar | 단계식 교육 과정과 노래 연습 도구 | [조사 폴더](justinguitar/README.md) |
| Ultimate Guitar | 탭·코드 라이브러리와 재생 제어 | [조사 폴더](ultimate-guitar/README.md) |
| Guitar Tricks | 코어 학습 경로와 구간 반복 레슨 | [조사 폴더](guitar-tricks/README.md) |

## 비교와 적용

- [서비스 종합 비교](synthesis.md): UI·UX, 기술 범위, 커리큘럼, 기능을 공통 항목으로 비교하고 muttan 적용점을 정리한다.
- 서비스별 하위 문서는 개요 → UI·UX → 기술 → 커리큘럼 → 기능 → 근거·한계 → muttan 적용 순으로 구성한다.

## 조사 원칙

공식 제품·도움말 문서는 기능과 사용 흐름의 1차 출처로 사용한다. 내부 알고리즘이 공개되지 않으면 추정하지 않고 미확인으로 기록한다. 사용자 리뷰와 구형 자료는 공식 현재 사양과 분리한다. 게시 시점 이후 달라질 수 있는 기능은 확인 날짜를 함께 적는다.
