# Fender Play · 조사

## UI·UX 관찰

- 경로는 다음 행동을 제공하여 학습자가 다음 레슨을 찾아 헤매지 않게 한다.
- 곡을 짧은 섹션으로 나누고 전체 연주로 이어지게 한다.
- 리프는 노래 전체보다 짧은 인식 가능한 멜로디를 먼저 연주하게 한다.
- 타브 중심의 플레이 화면과 설명 영상 중심의 강의를 구분한다.
- Feedback Mode는 도움말에서 베타로 기술되어 있고, 특정 곡·리프 연습에서 제공된다. 이를 전체 카탈로그 공통 기능으로 일반화하지 않는다.

## 화면에서 확인할 수 있는 콘텐츠 패턴

교육자 문서는 Play Along에서 악기 클로즈업과 화면 아래를 지나가는 타브 또는 코드가 함께 보인다고 설명한다. Practice Mode는 영상 없이 타브만 제공하는 독립적인 연습 콘텐츠다. 따라서 영상 학습과 악보 단독 연습은 한 화면에 항상 합치기보다 목적에 따라 분리된다. [노래 레슨 종류](https://lausd-instructor.fender.com/hc/en-us/articles/360048940851-Different-Types-of-Song-Lessons)

Feedback Mode 안내는 이를 베타로 표기하며 특정 Song/Riff 과정에서만 찾을 수 있다고 한다. 연주 입력·예제 소리·반주 트랙을 선택하는 사용 흐름이 있고, 반주 트랙을 재생하면서 입력할 때 헤드폰을 권한다. 오디오 피드백을 제품 전체에 적용되는 상시 채점 기능으로 해석하면 안 된다. [Feedback Mode 안내](https://lausd-instructor.fender.com/hc/en-us/articles/4423659951373-Feedback-Mode)

## 공개된 Feedback Mode 화면

![Fender Play Feedback Mode results screen](https://images.ctfassets.net/r1mvpfown1y6/7vYjcLzUXvO7riwxZyQ86U/3a34549a8ca10040a69bcad0372cc1d6/Play_Mobile_3.png)

Fender 공식 제품 페이지의 화면은 연주가 끝난 결과 화면이다. 종합 점수 링과 리듬·피치 점수, 플레이 길이 막대, 다시 시도·닫기를 제시한다. 이는 교육자 도움말에서 Feedback Mode가 베타라고 밝힌 것과 함께 봐야 한다. 곡 연주 화면 전체나 오류가 발생한 순간의 피드백 UI는 이 이미지로 확인할 수 없다. 이미지 출처: [Fender Play](https://www.fender.com/play).
