# Simply Guitar · 조사

## UI·학습 설계에서 관찰한 점

- 플레이 중 자주 필요한 코드 참고를 별도 탐색 깊이 없이 곡 화면에서 연다.
- 코드 다이어그램, 이미지, 영상은 필요할 때 보는 보조 설명이다.
- 화면을 가사·코드가 같이 진행되는 플레이 영역으로 구성한다.
- 공개 도움말은 가사 포함이라고 기술하지만, 구체적인 자동 스크롤·재생 속도·오류 감지 동작은 확인되지 않는다.

## 공개 도움말로 확인한 진행 화면의 관찰 범위

PLAY 도움말은 곡을 시작하면 가사·코드가 함께 나오고 자동으로 스크롤되며 Basic/Full 스트럼 버전을 선택한다고 설명한다. 상단의 코드를 눌러 운지 도움말로 이동할 수 있다. 아래 이미지는 인앱 화면 캡처라기보다 기능을 설명하는 공식 도움말이므로, 구체적인 픽셀 레이아웃의 증거로 사용하지 않는다.

이미지 캡처를 문서에 추가할 수 있는 현재 공식 공개 화면 자료를 발견하지 못했다. 텍스트로 확인한 동작과 보지 못한 실제 레이아웃을 구분한다. [PLAY 도움말](https://piano-help.hellosimply.com/en/articles/14588852-what-is-play-in-simply-guitar)
